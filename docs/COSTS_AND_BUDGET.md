# Costs and Budget

## Model Pricing (Reference)

| Model | Provider | Input (per 1K tokens) | Output (per 1K tokens) | Notes |
|-------|----------|----------------------|------------------------|-------|
| GPT-5.4 | Azure Foundry | ~$0.01 | ~$0.03 | Complex reasoning, planning |
| Gemini 2.5 Flash | Google AI | ~$0.00035 | ~$0.00105 | Fast ops, content, monitoring |

> Prices are estimates. Verify current pricing in the provider dashboard.
> Update the `models` table in Supabase if prices change.

## Budget Policy

### Default Configuration

```bash
MONTHLY_BUDGET_USD=500
ALERT_THRESHOLD_PERCENT=80
```

### Alert Levels

| Level | Trigger | Action |
|-------|---------|--------|
| Info | > 50% budget used | Log to events |
| Warning | > 80% budget used | Telegram notification to Neb |
| Critical | > 100% budget used | Telegram + log `budget_exceeded` event |

### Per-Task Budget

- A single task should not exceed $5 in model costs
- Tasks exceeding $2 trigger a warning log
- Finance Agent checks this after each run

## Cost Tracking

Every LLM call creates a record in `runs`:

```typescript
// backend/src/services/logger.ts
cost_usd = (tokens_input / 1000) * model.cost_per_1k_input_tokens
         + (tokens_output / 1000) * model.cost_per_1k_output_tokens
```

The Dashboard **Costs** view shows spend by agent and model in real time.

## Cost Optimization

### 1. Model Routing

Route simple tasks to Gemini 2.5 Flash (10–30x cheaper than GPT-5.4):

```
Complex task → GPT-5.4 (~$0.02–0.10 per task)
Simple task  → Gemini 2.5 Flash (~$0.001–0.005 per task)
```

Model assignments per agent are in `backend/src/config/models.ts`.
Override temporarily with: `/assign_model <agent_id> gemini-2.5-flash`

### 2. Context Management

- Agent memory uses deterministic hash embeddings — no embedding API cost
- Memory recall runs before each LLM call but only for task-bound runs
- Deduplication threshold (0.65) prevents memory bloat

### 3. Cron Optimization

- Ops: one check per 15 min (not per minute)
- Finance: one budget check per hour
- HR: digest computed once per 6 hours

### 4. LLM Streaming

All LLM calls use `stream: true` to avoid proxy timeout issues (LiteLLM default timeout is short for large outputs).

## Billing Setup

### Azure OpenAI

- Set spending limit in Azure Portal
- Configure billing alerts at 50%, 80%, 100% of monthly limit
- Use a dedicated resource group for WAI

### Google AI (Gemini)

- Enable billing budgets in Google Cloud Console
- Set alert at 80% of monthly allocation

### Supabase

- Free tier sufficient for development
- Monitor database size and API calls in Supabase Dashboard → Usage
- Upgrade to Pro when approaching free tier limits (500MB DB, 2GB bandwidth)
