| Level | Trigger | Action |
|-------|---------|--------|

- Tasks exceeding $2 should log a warning

## Cost Tracking

Every LLM call creates a record in `runs`:

```sql
INSERT INTO runs (agent_id, model_id, tokens_input, tokens_output, cost_usd, ...)
VALUES (...)
```

Cost is calculated as:
```typescript
cost_usd = (tokens_input / 1000) * model.cost_per_1k_input_tokens
         + (tokens_output / 1000) * model.cost_per_1k_output_tokens
```

## Cost Optimization Strategies

### 1. Model Routing
Route simple tasks to Gemini 2.5 Flash (10-30x cheaper than GPT-5.4).

```
Complex task → GPT-5.4 (~$0.02-0.10 per task)
Simple task  → Gemini 2.5 Flash (~$0.001-0.005 per task)
```

### 2. Context Management
- Use `/compact` in OpenClaw sessions to reduce context size
- Truncate agent memory after 10 completed tasks
- Store compressed summaries instead of full transcripts

### 3. Cron Optimization
- Batch monitoring tasks (one check per 15 min instead of per minute)
- Finance Agent aggregates in one query, not N queries

### 4. Tool Use
- Prefer structured queries over LLM interpretation
- Cache browser results where possible

## Billing Setup

### Azure OpenAI
- Set spending limit in Azure Portal
- Configure billing alerts at 50%, 80%, 100% of monthly limit
- Separate resource group for WAI (easy cost tracking)

### Google AI
- Enable billing budgets in Google Cloud Console
- Set alert at 80% of monthly allocation

### Supabase
- Free tier sufficient for development
- Monitor database size and API calls in Supabase Dashboard
- Upgrade to Pro plan when approaching free tier limits
