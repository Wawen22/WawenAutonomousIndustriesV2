# Migration Note — T135 LeadSource inbound

The `leads` table `source` column CHECK constraint was created in `20260326030000_leads.sql`.
To add `'inbound'` to the allowed values, run the following in the Supabase SQL Editor:

```sql
ALTER TABLE leads DROP CONSTRAINT IF EXISTS leads_source_check;
ALTER TABLE leads ADD CONSTRAINT leads_source_check
  CHECK (source IN ('website_audit', 'google_maps', 'manual', 'freelance', 'inbound'));
```

This cannot be done via a new migration file without recreating the constraint, so it is applied manually.
